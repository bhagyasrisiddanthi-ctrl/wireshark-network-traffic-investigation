# Wireshark-Based Network Traffic Investigation

## Project Overview
This project analyses the SBT-PCAP1 network capture using Wireshark to understand network communication and investigate unusual activity.

## Objectives
- Analyse IP addresses and network conversations.
- Identify protocols and ports.
- Examine ARP and DNS traffic.
- Understand the TCP three-way handshake.
- Analyse HTTP communication using Follow TCP Stream.
- Investigate ICMP messages, TCP resets, and slow ping responses.

## Tools Used
- Wireshark
- Display Filters
- IPv4 Conversations
- Protocol Hierarchy Statistics
- Follow TCP Stream

## Key Findings
- Analysed TCP, TLS, UDP, DNS, HTTP, and ICMP traffic.
- Investigated ICMP Port Unreachable messages and TCP resets.
- Observed a Galaxy-S8 device requesting an IP address.
- Identified slow ping responses.

## Conclusion
We did not find clear evidence of malicious activity in the SBT-PCAP1 capture. Some unusual observations may require further investigation.
